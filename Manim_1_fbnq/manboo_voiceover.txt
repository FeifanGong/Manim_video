今天推导斐波那契数列通项公式。

它满足：F 零等于零，F 一等于一，后一项等于前两项之和。

我们的目标，是求出 F n。

关键想法是：高中数列里，等比数列最容易写通项。所以，我们要把二阶递推，改造成一个新的等比数列。

第一步，设一个新数列 G n，等于 F n 加一，减去阿尔法倍 F n。

我们希望它满足：G n 加一，等于贝塔倍 G n。

把 G n 和 G n 加一代回去，再和原来的递推式比较系数，就得到两个条件：

阿尔法加贝塔等于一，阿尔法乘贝塔等于负一。

也就是说，阿尔法和贝塔，是方程 x 平方减 x 减一等于零的两个根。

第二步，解这个一元二次方程。

可以得到：阿尔法等于一加根号五，除以二；贝塔等于一减根号五，除以二。

后面真正要用的是：阿尔法减贝塔等于根号五。

第三步，利用初值 F 零等于零，F 一等于一。

这时两个新数列的首项都是一，所以它们的通项分别是贝塔的 n 次方，和阿尔法的 n 次方。

把它们换回 F 的表达式，就得到一个关于 F n 加一和 F n 的方程组。

第四步，我们想要求的是 F n，但方程组里还混着 F n 加一。

所以把两式相减，F n 加一正好被消掉，只剩下 F n。

再利用阿尔法减贝塔等于根号五，可以得到：

F n 等于阿尔法的 n 次方，减去贝塔的 n 次方，再除以根号五。

最后，把阿尔法和贝塔的具体值代回去，就得到斐波那契数列的通项公式，也就是比内公式。

这就是从递推到通项的高中数列路线。
